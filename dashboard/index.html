How a number is earned

Each category carries its own FDV/TVL multiple (chains 2.20×, DEX 1.10×, lending 0.85×, curators 0.55×, stables 0.50×). Growth moves the score with clamped 7-day TVL change, longevity rewards years already live with no token on record, and breadth adds 3% per extra chain up to five. Protocols that already record a token are counted separately and never ranked here.
